Everything included

Production concerns, already handled

No glue code, no half-finished admin. Auth, streaming, retrieval, quotas, API and tests ship in the box.

Token streaming

WebSocket deltas render with a live caret, then swap to sanitized Markdown when the reply completes.

Document grounding

PDF, DOCX, Markdown and text files are chunked, embedded and retrieved per conversation or globally.

Provider agnostic

One OpenAI-compatible adapter covers OpenAI, Azure, Groq, OpenRouter, Together, Ollama and LM Studio.

Usage quotas

Every completion and embedding is metered. Monthly allowances reset automatically and block at the limit.

REST API + JWT

Conversations, messages and documents are scriptable with per-user throttling and pagination.

Secure by default

Custom email-first users, CSRF-protected forms, sanitized Markdown and owner-only querysets.

Browse the API
shell 
# 1. Get an access token
curl -s http://localhost:8000/api/v1/auth/token/ \
  -H "Content-Type: application/json" \
  -d '{"email":"you@example.com","password":"…"}'

# 2. Create a conversation
curl -s http://localhost:8000/api/v1/conversations/ \
  -H "Authorization: Bearer $ACCESS_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"title":"From the API"}'

# 3. Send a message
curl -s http://localhost:8000/api/v1/conversations/<id>/messages/ \
  -H "Authorization: Bearer $ACCESS_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"content":"Summarize the docs"}'
